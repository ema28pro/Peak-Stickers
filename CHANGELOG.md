# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-23

### Added

- **"Generar stickers"** button inside the customization passport (customization notebook).
- PNG stickers with a **transparent background** and **white sticker border**, generated from the character's 3D model with its current outfit.
- All poses captured: 22 emote wheel emotes + 8 idle pose variants.
- Pose dropdown in-game: all poses, emotes only, idles only, or a single pose.
- Border thickness slider (0-40 px) directly in the passport UI.
- Sticker-style rounded border (small gaps and details are smoothed out).
- Automatic per-pose camera framing (nothing gets cut off) and auto-crop to fill the image.
- Per-pose sample frame configuration (`SampleTimes`), tuned per animation by default.
- Options: output folder, resolution, border width, include idles, open folder when done.
- README images use absolute URLs so they render on Thunderstore; English store description.
