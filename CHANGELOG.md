# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-11-22

### Added

- **"Generar stickers"** button inside the customization notebook (passport).
- PNG sticker generation with a **transparent background** and **white border** from the character's 3D model with their current outfit.
- Capture of all poses: all 22 emote wheel emotes + 8 idle pose variants.
- Configurable sample frame per pose (`SampleTimes`), with default values tailored to each animation.
- Configuration options: output folder, resolution, border width, include idles, and open folder when done.
